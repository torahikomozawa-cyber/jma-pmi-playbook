01受付（来院時対応）

— / —

最初の接点。挨拶と振り分け（トリアージ）の精度が回転と体験を決める。

S
来院した患者に即座に顔を上げ、「こんにちは」と明るく挨拶している
—
Q
保険証・マイナンバーカードの確認と資格確認を漏れなく実施している
—
Q
問診票の案内が全スタッフ同一手順で行われている
—
Q
症状の聞き取りから検査パターンへの振り分け（トリアージ）が正しく行われている
—
S
受付時に待ち時間の目安を伝えている体験目標：30分以内に診察・1時間以内に帰宅
—
S
待たせてしまった際に「お待たせして申し訳ございません」の一言を添えている
—
C
受付カウンターに私物・書類の放置がなく、整頓されている
—
C
患者が使う筆記具・バインダーが清潔に保たれている（定期清拭）
—

02予約管理

— / —

予約リストの事前確認と再来予約の取り切りが軸。

Q
当日の予約リストを診療開始前に確認し、全スタッフで共有している
—
Q
予約患者と飛び込み患者の受付順ルールが決まっており、全員が同じ運用をしている
—
S
再来予約は「医師が診察時に伝える→受付で即時取得」の流れが徹底されている
—
Q
手術相談・術前検査の患者を通常診療と区別し、適切な枠・日程に振り分けている
—

03電話対応

— / —

電話の品質＝集患の品質。

S
3コール以内に応答し、クリニック名を名乗っている
—
Q
症状の緊急度を聞き取り、強い痛み・急激な視力低下は当日来院を案内している
—
S
日時・氏名・連絡先を復唱して確認している
—
S
保留は30秒以内を目安とし、長引く場合は折り返しを提案している
—
Q
アクセス・持ち物（保険証・お薬手帳・使用中の眼鏡やコンタクト）を案内できる
—

04患者対応（診察前後・会計・見送り）

— / —

院内での体験全体。接客ワードの統一と会計時の次回予約声がけが要点。

S
呼び出しは明瞭に、語尾を伸ばさずはきはきとした印象で行い、高齢の方には近づいて声がけしている
—
S
次のご案内に移る時に、「お待たせしました」の声を必ずかけている
—
S
散瞳の待機時間（約20分）など、待ちの理由と目安を説明している
—
Q
散瞳後の見えづらさ・運転への注意を、帰宅前に口頭で説明している
—
Q
会計金額の確認・処方箋の渡し忘れ防止のダブルチェックが行われている
—
S
会計時に次回来院・予約の声がけをしている
—
S
見送りの言葉が「お大事にどうぞ」「お大事になさってください」で統一され、受付のみでなく複数人で声をかけて送り出している
—
Q
滞在1時間を超えそうな患者に、状況説明の声がけができている
—

05院内環境（C）

— / —

診療開始前に確認。清潔感は院の第一印象と信頼に直結する。

C
待合室の椅子・床にゴミ・汚れがない（診療開始前に確認）
—
C
トイレの清掃・備品補充（ペーパー・石けん）がされている
—
C
検査機器のあご台・額当てが患者ごとに清拭されている
—
C
院内掲示物に破れ・古い情報がない（診療案内が最新の内容）
—
C
入口ガラス・看板が清潔で、診療時間表示が最新の内容になっている
—
